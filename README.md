# 🍿 MiCine Web3 - DApp de Boletaje Descentralizado

Una aplicación web3 completa (Full-Stack) para la gestión y compra de boletos de cine utilizando la red de prueba Ethereum (Sepolia).

## 🚀 Tecnologías Utilizadas

*   **Frontend:** Angular 17, HTML/CSS (Responsive Dark Mode), Ethers.js
*   **Smart Contracts:** Solidity, Hardhat, OpenZeppelin (ERC20 y ERC721)
*   **Base de Datos:** Google Firebase (Firestore) para catálogos dinámicos
*   **Despliegue:** Netlify (Frontend) y red Sepolia (Contratos)

## ⚙️ Características Principales

1.  **Pagos con Tokens ERC20:** Integración de un token personalizado (`CIN`) con un faucet automatizado para pruebas.
2.  **Boletos como NFTs:** Al realizar una compra exitosa, se mintea un NFT (ERC721) directamente en la billetera del usuario.
3.  **Catálogo Dinámico:** Películas, horarios y metadatos alojados en la nube para una carga eficiente.
4.  **Generación y Validación QR:** Creación dinámica de códigos QR inyectados con datos del boleto y rutas validadoras.
